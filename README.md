# Employee Management Dashboard

A full-stack Employee Management Dashboard built using the MERN stack with secure authentication, employee CRUD operations, search, filtering, pagination, and analytics.

## Tech Stack

- React
- TypeScript
- Node.js
- Express.js
- MongoDB
- Tailwind CSS
- JWT Authentication

## Features

- User Authentication
- Employee CRUD
- Search & Filter
- Pagination
- Dashboard Analytics
- Protected Routes
- Responsive UI

## Installation

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
